FLEET CYCLING v1.3 vs v1.4 — SIDE BY SIDE TICK 0

Both columns run the same simulated fleet on the same clock. Left is the rule shipped in v1.3; right is the v1.4 rule (approved and shipped). With a printing printer, the v1.3 rule never reaches a vector animation — the panel only alternates camera and status, because the resting face was gated on p.state === "idle". v1.4 gives a resting instrument to any printer that is not in ERROR or OFFLINE. Simply deleting the idle gate is not enough: camHolder advances with tick, so at FLEET 2 v1.3's (tick + idx) % 2 test would put every rest turn where the status turn belongs and the readout would never show. v1.4 uses a period of 3 for status/rest, which keeps all three faces reachable at every fleet size (checked for 1–10 printers), and still rotates the instrument kind over time. Not simulated here: the print-complete face, which takes priority over all of these in both versions.
