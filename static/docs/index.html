OVERVIEW

WHAT LAB CONSOLE IS AND HOW IT FITS TOGETHER

Lab Console is a wall-mountable web dashboard for monitoring and controlling a fleet of Bambu Lab 3D printers (1–10) over the local network. It runs on a Raspberry Pi 3 or newer and is viewed in any browser — typically a small touch screen mounted in the lab. The fleet view gives an at-a-glance state for every printer; tapping a panel opens a full console with a live camera, telemetry, and controls including pause, resume, stop, and starting new prints.

01 ARCHITECTURE AT A GLANCE

The Pi holds one always-on MQTT connection per printer (Developer Mode, TLS, port 8883) for status and control, relays one live camera at a time to the browser as MJPEG, browses and receives print files over FTPS, and listens for SSDP announcements so printers are found again after DHCP address changes. Browsers get state pushed over a WebSocket — nothing polls the printers.

02 DEMO MODE

The console can run against a simulated fleet — no printers contacted, no config file needed. It exercises every state on a timer (printing with advancing progress, idle with resting animations, a recurring ERROR with the flashing bezel, and a temporary offline drop), and all controls act on the simulation. Use it for training new lab members or evaluating changes safely:

python3 server.py --demo

A pulsing violet DEMO badge appears in the status bar whenever the simulated fleet is active, so it can never be mistaken for the live lab.
