OPERATOR GUIDE

READING AND OPERATING THE FLEET CONSOLE

01 READING THE DASHBOARD

The dashboard is the default wall view. The status bar across the top shows fleet totals (idle / printing / error / offline), the console clock, and a LINK indicator for the browser’s connection to the Pi — if LINK is red, what you see may be stale.

Each printer is a bezel-framed panel. Panels cycle automatically every ~8 seconds between three faces: the status readout, an ambient scanner animation (idle printers only), and — for one printer at a time — the live camera slot, which rotates through the fleet. The state lamp in each panel’s header never cycles away, so fleet state stays readable from across the room. Tap any panel to open its detail console.

02 PRINTER STATES

IDLE Steady cyan. Online and ready. Readout shows temperatures and the last job.
PRINTING Pulsing amber. Shows file name, layer count, nozzle/bed temperatures, time remaining, and progress.
PAUSED Steady violet. The job is held and can be resumed from the detail view.
ERROR Blinking red — and the entire panel bezel flashes red in sync. The readout lists HMS code(s). Error panels never cycle away to other faces.
OFFLINE Dark lamp. No MQTT link — check power, network, and Developer Mode.

03 CAMERA VIEWS

One camera relay runs at a time; on the dashboard the live slot rotates through the fleet automatically, and opening a detail view pins that printer’s camera. What the feed looks like depends on the hardware:

  • X1 Carbon / H2D — real video (RTSPS), relayed at a reduced frame rate to keep the Pi comfortable.
  • A1 / A1 Mini — the printer’s chamber camera provides roughly one frame per second. The slideshow feel is the hardware’s design, not a fault.
◈ NOTE

The white ● LIVE tag is an indicator, not an alarm — red is reserved exclusively for error signaling. A grey NO SIGNAL tag means liveview is unavailable for that printer; status and controls still work.

04 CONTROLS

All controls live in the detail console (tap a panel). Buttons grey out when they don’t apply to the printer’s current state.

CONTROLBEHAVIOR
⏸ PAUSE / ▶ RESUMEHolds or resumes the running job. The button swaps depending on state. Resume also clears a recoverable ERROR (e.g. after feeding new filament).
■ STOPAborts the job. Asks for confirmation first (see caution below).
☼ LIGHTToggles the chamber light — useful before judging a camera view.
▲ START PRINT…Opens the file dialog: pick a sliced .3mf already on the printer’s SD card, or upload one from your device. Selecting a file arms the START button.
▲ CAUTION

STOP cannot be undone — a stopped job restarts from zero. The console always asks for confirmation before sending it.

◈ GOOD PRACTICE

Before starting a print remotely, use the camera to confirm the bed is clear. The console cannot see what the camera cannot.
